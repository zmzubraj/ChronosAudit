# Conceptual schematic source

The paper's conceptual figure is represented by `../diagrams/architecture.mmd`.
It separates three evidentiary views of the same frozen cohort: temporal eligibility,
identity abstraction, and observable proxy linkage. All arrows are data-flow arrows;
none represents causality. The gate from historical envelopes to canonical rows is
fail-closed. The final human/independent-review node is an authority gate, not a
computed scientific result.

Accessibility summary: a 417-case SCONE-bench index feeds verified dual-provider
historical envelopes. Valid rows branch into temporal, identity, and proxy analyses,
which converge into editable tables, figures, and a manuscript. Reproducibility and
PDF checks precede independent review and accountable-author approval.
