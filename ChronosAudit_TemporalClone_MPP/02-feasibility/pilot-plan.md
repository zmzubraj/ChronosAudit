# Pilot disposition

## Decision

No new pilot is required for the bounded descriptive questions in this MPP. The complete frozen 417-case cohort is reused read-only, and the analysis is deterministic.

## Why this is not an efficacy pilot

The paper does not estimate detector accuracy, intervention effect, vulnerability prevalence, or a population parameter. Its estimands are finite-cohort counts under four predeclared temporal landmarks, four identity abstractions, and a specified observable proxy-indicator rule.

## Substitute verification sequence

1. Unit-test timestamp and bytecode normalization rules.
2. Run the analysis over all 417 closed envelopes.
3. Reconcile result tables against the canonical result JSON.
4. Rebuild figures and the PDF from frozen derivatives.
5. Require an independently owned reproduction before public upload.

This disposition remains a draft until an independent verifier confirms that a separate pilot is not needed for the narrowed claims.
