# Novelty Claim Specification

## Claim N1

Within the bounded search described in `search-protocol.md`, no located predecessor jointly audits the current 417-row SCONE-bench cohort for pre-incident landmark existence, dual-provider block-hash-pinned historical state, progressively stronger runtime-code identities, and observable proxy/minimal-proxy linkage.

## Materiality threshold

The contribution is materially differentiating only if all of the following survive review:

- it uses the current 417-case cohort rather than a generic smart-contract corpus;
- all case inputs are hash-bound and strict historical snapshots are closed;
- temporal eligibility is reported at prespecified landmarks using deployment time;
- exact and metadata-stripped runtime identities are both reported;
- ERC-1967/beacon/ERC-1167 linkage is measured separately from bytecode identity; and
- the analysis produces a reproducible artifact bundle, not only prose recommendations.

## Defeating evidence

A credible paper, preprint, benchmark release, or technical report that already reports the same joint audit on the same cohort with comparable or stronger provenance defeats N1. A predecessor covering only historical forks, only code clones, only proxy detection, or only benchmark contamination qualifies but does not by itself defeat the joint claim.

## Bounded wording

Allowed: “We present a reproducible validity audit of SCONE-bench along temporal and contract-identity dimensions.”

Prohibited: “first ever,” “proves benchmark invalid,” “eliminates contamination,” “independent replication,” or any universal novelty claim.
